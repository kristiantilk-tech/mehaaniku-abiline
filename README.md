# Mehaaniku abiline

Muruniiduk.ee töökoja mehaaniku häälabilise väljalasked.

Pakett on krüpteeritud – programmi avamiseks on vaja töökoja uuenduste võtit, mida siin hoidlas ei ole.
Seadeid, võtmeid ega paroole siin ei hoita.

Paigaldus töökoja arvutisse: käivita **Paigalda abiline.bat**. Edaspidi uueneb abiline ise.
